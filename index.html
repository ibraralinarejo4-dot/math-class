Mathematics

Chapter 1: Matrices and Determinants

Concept: What is a Matrix?

Real numbers ko brackets me tarteeb se likhne ko Matrix kehte hain. (e.g., [1 2; 3 4]).

Solved Example

Find Order: Matrix [2 3; 1 0] has 2 rows and 2 columns. So its order is 2-by-2.

Exercise 1.1 Solution

Q1: Find order of B = [2 0; 3 5]
Answer: It has 2 rows and 2 columns. Order = 2-by-2.

Physics

Chapter 1: Physical Quantities & Measurement

Concept: Physical Quantities

Un tamaam cheezon ko jinhe napa (measure) ja sake, unhe physical quantities kehte hain (e.g., Length, Mass).

Solved Example

Convert 50 km/h to m/s: (50 × 1000) / 3600 = 13.88 m/s.

Exercise 1.1 Solution

Q1: Difference between Base and Derived?
Base quantities automatic hoti hain (Mass), derived unse banti hain (Speed).

Chemistry

Chapter 1: Fundamentals of Chemistry

Concept: Element and Compound

Element: Jo ek hi qisam ke atoms se bana ho (e.g., Oxygen O₂).
Compound: Jo mukhtalif elements se mil kar bane (e.g., Water H₂O).

Solved Example

Calculate molecular mass of H₂O: H(1×2) + O(16) = 18 amu.

Exercise 1.1 Solution

Q1: Define Valency.
Kisi element ki doosre elements ke sath milne ki quwwat (combining capacity) ko valency kehte hain.
